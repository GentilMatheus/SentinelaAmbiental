# 🌱 Sentinela Ambiental
O Sentinela Ambiental é um aplicativo de celular que ajuda os moradores a avisarem sobre problemas na cidade, como lixo na rua, esgoto vazando ou queimadas, 
guardando a localização do problema para que ele possa ser consertado.
# 📌 Requisitos para rodar o aplicativo

Para abrir e rodar este projeto em outro computador, você precisará apenas do Python instalado e da biblioteca FLET.

# Extensão necessária
Abra o Prompt do computador e execute o comando abaixo para instalar o framework visual do aplicativo.

```bash
pip install flet
